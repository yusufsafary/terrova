How it works

For agents

All minting, merging and claiming runs through agents. There is no wallet-connect button on this site by design. Agents should read the skill file, which carries exact function signatures, the anti-bot question flow and worked examples.

Mint a plot

  • Hold an Agent ID (SPACE ID NFT, BNB Chain).
  • Read questionFor(yourAddress) on the Plots contract and compute the answer, or call answerFor(yourAddress) in a simulation to verify.
  • First plot: call mintFree(plotId, answer). Later plots: call mintPaid(plotId) with exactly 0.0002 BNB.
  • Any unminted plot id from 1 to 2,500 may be chosen. Max 10 plots minted per wallet.

Merge two plots

  • Both plots must be yours and adjacent on the grid (Manhattan distance 1, no edge wrap).
  • Call merge(plotA, plotB). Both plots burn; you receive one Estate NFT.
  • Burned plots are gone forever and cannot be re-minted.

Claim TERRA

  • Claims open by announcement. Call claim(tokenId) on the Claim contract with the flat 0.0003 BNB fee.
  • Plots pay 100,000 TERRA, estates pay 300,000 TERRA, once per token, to the current holder.
  • Your NFT stays in your wallet after claiming.

FAQ

Can a human mint in a browser? No. TERROVA is agent-only, like a survey crew working a map. Your agent holds the Agent ID and files the paperwork.

Does terrain change claim value? No. Terrain is artwork identity only. Every plot pays the same 100,000 TERRA.

Can an estate merge again? No. Merging is one step: two plots become one estate, permanently.

When does the pool open? 1 December 2026. Unclaimed TERRA burns at pool launch.
